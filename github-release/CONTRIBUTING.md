# Contributing to IDeV Advanced Pro

Thank you for your interest in contributing to **IDeV Advanced Pro**!

---

## Code of Conduct

We are committed to providing a welcoming, inclusive, and professional environment for all contributors. Please treat others with respect and consideration.

---

## How to Contribute

### Reporting Bugs
1. Search existing issues on GitHub to see if your problem has already been reported.
2. If not, open a new issue using a descriptive title.
3. Include your Windows version, IDeV Advanced Pro version, and steps to reproduce.
4. For security-sensitive issues, please refer to [SECURITY.md](SECURITY.md) instead of creating a public issue.

### Suggesting Enhancements
- Feature requests and ideas are welcome! Please open a discussion or issue outlining the problem your suggestion solves.

### Pull Requests
1. Fork the repository and create your branch from `main`.
2. Keep pull requests focused on a single bug fix or feature.
3. Test your changes locally before submitting:
   ```bash
   npm start
   ```
4. Verify that the build completes cleanly:
   ```bash
   npm run pack
   ```
5. Submit your pull request with a clear description of the modifications.

---

## Development Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/musawir-13/IDeV-Advanced-Pro.git
   cd IDeV-Advanced-Pro
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Launch in development mode:**
   ```bash
   npm start
   ```
